# Super Mario Bros. 1-1 Classic Remake

ブラウザだけで遊べるスーパーマリオブラザーズ1-1の完全再現版です。Kaboom.js を使い、地形・敵配置・旗降ろし演出まで作り込み直しました。

## 操作方法
- ← / →: 移動
- X / J / Space / W / ↑: ジャンプ
- S: ダッシュ（速度アップ）

## 開発メモ
- すべてのアセットは CDN から読み込み、ビルド工程なしで動作します。
- `main.js` の `buildLevelGrid` でステージ構造を生成しています。タイルサイズは 16px、重力は 1600 で NES 感のある挙動に調整しています。
